# Рецепты чартов для дашборда BI_DWH

Шпаргалка: для каждого графика — тип, dataset, какие метрики/фильтры/форматы
указывать. Открывай чарт в Superset (`Explore`) и сверяйся с таблицей.

> Везде: **Metric** = то, что считаем; **Filters** = ограничения строк;
> **Number format** = как показывать число.

---

## 0. Общие правила (важно!)

1. **KPI и MoM — это ОДНА строка витрины.** После фильтров
   (`agg_level` + `month_key`) остаётся одна строка → любая агрегация
   (SUM/AVG) вернёт её значение.
2. **Фильтр `agg_level` обязателен** на KPI и MoM, иначе усредняются
   все уровни (мы на этом обожглись: 226% вместо −5%).
3. **Метрика MoM — колонка `mom_*`**, не `stock_value`.
4. **Формат MoM — `%`**, денег — `,.0f` (без валюты в формате, «₽» в заголовке).

## 2. MoM-карточки (Big Number) — 4 штуки

Тип: **Big Number (Total)**. Dataset: `vw_turnover_metrics`.
**Фильтры те же, что у KPI: `agg_level = 'company'` + `month_key`** — иначе
бессмыслица (усреднение по всем уровням).

| Карточка | Metric | Number format |
|---|---|---|
| MoM суммы запасов | `AVG(mom_stock_value)` | `.1%` |
| MoM среднего остатка | `AVG(mom_avg_stock_value)` | `.1%` |
| MoM оборачиваемости (разы) | `AVG(mom_turnover_ratio)` | `.1%` |
| MoM оборачиваемости (дни) | `AVG(mom_turnover_days)` | `.1%` |

Ожидаемые значения (декабрь-2025, компания): `-5.0%`, `-4.4%`, `+4.8%`, `-4.6%`.

## 3. Графики динамики (Line)

### 3.1. Сумма запасов по месяцам

Тип: **ECharts Timeseries Line**. Dataset: `vw_turnover_metrics`.

| Параметр | Значение |
|---|---|
| X axis | `month_key` (или computed `month_dt`, см. ниже) |
| Metric | `SUM(stock_value)` |
| Filters (чарта) | `agg_level = 'company'` |
| Number format | `,.0f` |
| Sort | по `month_key` по возрастанию |

**Про «месяцы на оси»:** `month_key` — число (`202401`). Чтобы ось была
понятной, в dataset добавь **Computed column**:
- Name: `month_dt`
- Expression (SQL): `DATEFROMPARTS(year_num, month_num, 1)`
- Type: Date

И в чарте ставь X = `month_dt`. Подписи оси: в настройках оси → формат даты.

**Исключи этот график из фильтра «Месяц»** (Scope фильтра → снять галку),
чтобы он всегда показывал все 24 месяца.

### 3.2. Оборачиваемость в днях по месяцам

Тип: **ECharts Timeseries Line**. Dataset: `vw_turnover_metrics`.

| Параметр | Значение |
|---|---|
| X axis | `month_dt` |
| Metric | `AVG(turnover_days)` |
| Filters | `agg_level = 'company'` |
| Number format | `.1f` |

## 4. Структура (для ролей)

### 4.1. По дирекциям — Pie

Тип: **Pie Chart**. Dataset: `vw_turnover_metrics`.

| Параметр | Значение |
|---|---|
| Dimension (куски) | `directorate` |
| Metric | `SUM(stock_value)` |
| Filters | `agg_level = 'directorate'`; `month_key = 202512` |
| Label | `directorate` (или «дирекция: значение») |
| Number format | `,.0f` |

Дирекций немного → пирог читается. Включи легенду и подписи.

### 4.2. По цехам — Bar (не пирог!)

Тип: **ECharts Timeseries Bar** (или Bar). Dataset: `vw_turnover_metrics`.

| Параметр | Значение |
|---|---|
| X axis | `shop_code` |
| Metric | `SUM(stock_value)` |
| Filters | `agg_level = 'shop'`; `month_key = 202512` |
| Number format | `,.0f` |
| Опция «Top N» | 15–20 (остальное в «другие»), иначе бар нечитаем |

Цехов много → пирог с сотней кусков не годится, только столбики.

### 4.3. По складам — Bar или Table

Тип: **ECharts Timeseries Bar** или **Table**. Dataset: `vw_turnover_metrics`.

| Параметр | Значение |
|---|---|
| X axis / Columns | `warehouse_code` |
| Metric | `SUM(stock_value)` |
| Filters | `agg_level = 'warehouse'`; `month_key = 202512` |
| Number format | `,.0f` |
| Top N | 15–20 |

### 4.4. Детализация по материалам — Table («копать вглубь»)

Тип: **Table**. Dataset: `vw_inventory_monthly`.

| Параметр | Значение |
|---|---|
| Columns | `month_key`, `warehouse_code`, `material_id`, `unit`, `balance_end`, `price`, `stock_value`, `turnover_days` |
| Metric | (не нужно, колонки уже есть) |
| Filters | `month_key = 202512` |
| Sort | `stock_value` по убыванию |
| Number format (колонки stock_value) | `,.0f` |
| «Показывать по X строк» | 50–100 |

Отвечает на вопрос: «из чего состоит сумма запасов?» — какой материал
на каком складе дороже всего.

## 5. Мелкие настройки «чтобы красиво»

| Что | Где | Как |
|---|---|---|
| Убрать рамку/тень | Style | прозрачный фон, тонкие рамки |
| Подписи осей | X/Y axis → Axis title | «Месяц», «₽», «дней» |
| Цветовая схема | Дашборд → Colors | одна схема на весь дашборд (по умолчанию ок) |
| Tooltip | форматы внутри тултипа | те же Number format |
| Пустые значения | Behave | «Не показывать» / «Как 0» — выбирай по смыслу |
| Big Number подпись | Subtitle | например «за декабрь 2025» |

## 6. Чек-лист «все чарты готовы»

- [ ] 4 KPI: правильные фильтры + `,.0f` / `.2f` / `.1f`
- [ ] 4 MoM: метрики `mom_*` + фильтры + `.1%`
- [ ] 2 Line: по месяцам, все 24 месяца
- [ ] Pie по дирекциям, Bar по цехам/складам (Top-N)
- [ ] Table по материалам
- [ ] Ни одного чарта без фильтра `agg_level` и месяца (кроме трендов)
