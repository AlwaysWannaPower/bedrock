# Презентация проекта BI_DWH

Одностраничная презентация для показа заказчику: архитектура, архитектурные
решения и их цена, ограничения системы, проверка реальными данными (графики),
ETL-пайплайн, метрики и запуск.

## Как запустить

1. Скопируйте папку `landing/` на компьютер заказчика (целиком, вместе с
   подпапкой `assets/`).
2. Откройте `index.html` двойным кликом — страница откроется в браузере.

**Интернет не нужен:** шрифты системные, изображение локальное, весь JS —
ванильный внутри файла, внешних запросов нет. Работает из любой папки и
даже с флешки.

## Структура

```text
landing/
├── index.html            ← страница (открывать её)
├── index-v2.html         ← архив предыдущей (светлой) версии, не основная
├── assets/
│   └── architecture.png  ← инфографика архитектуры (копия из docs/)
└── README.md             ← этот файл
```

## Что на странице

1. Hero — срез системы: реальные KPI компании (декабрь 2025) + статусы.
2. Поток данных — интерактивная схема слоёв с реальными счётчиками
   (наведение — подсказка).
3. Архитектурные решения — 8 решений: что выбрано, почему, «цена решения».
4. Ограничения — границы системы: данные заказчика, масштаб, архитектура.
5. Проверка данными — графики на реальных цифрах контрольного прогона:
   бары суммы запасов, объёмы по слоям со спарк-барами, карантин (донат).
6. ETL-пайплайн — 9 шагов (00–08) `elt.sp_master_etl` (аккордеон, клик раскрывает).
7. Метрики и роли — формулы и уровни срезов.
8. Запуск — развёртывание одной командой.

## Откуда взяты цифры

Все цифры — из реальных документов проекта (не выдуманы):

  состав карантина, пример витрины по месяцам, идемпотентность;
