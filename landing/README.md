# Презентация проекта BI_DWH

Одностраничная **презентация архитектуры** хранилища данных для показа
заказчику: слои данных, модель Кимбалла, метрики, ETL-пайплайн, запуск.
Без акцента на цифрах — справочный блок «Данные» вынесен последним.

## Как запустить

1. Скопируйте папку `landing/` на компьютер заказчика (целиком, вместе с
   подпапкой `assets/`).
2. Откройте `index.html` двойным кликом — страница откроется в браузере.

**Интернет не нужен:** шрифты системные, изображение локальное, весь JS —
ванильный внутри файла, внешних запросов нет. Работает из любой папки и
даже с флешки.

## Структура

```text
landing/
├── index.html            ← страница (открывать её)
├── assets/
│   └── architecture.png  ← инфографика архитектуры (копия из docs/)
└── README.md             ← этот файл
```

## Что на странице

1. **Hero** — формулировка решения и лента слоёв (файлы → staging →
   валидация → ods → dwh → datamart → BI). Без графики и без цифр.
2. **Слои данных** — 6 карточек: staging, quarantine, ods, dwh, datamart, elt.
3. **Модель данных** — схема «звезды»: факты и измерения, SCD2/SCD1,
   суррогатные ключи, UNKNOWN-плейсхолдеры.
4. **Метрики** — 4 показателя + MoM, уровни срезов = роли из ТЗ.
5. **ETL** — шаги `elt.sp_master_etl` (аккордеон, раскрывается).
6. **Запуск и надёжность** — развёртывание одной командой, SQL Agent,
   логирование/алерты, идемпотентность.
7. **Данные** (последний блок) — справочные цифры контрольного прогона:
   49 файлов первичной загрузки, ~5,9 млн строк, карантин, UNKNOWN-склады.
