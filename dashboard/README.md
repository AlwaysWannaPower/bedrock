# Папка /dashboard — материалы дашборда для сдачи

По ТЗ («Формат сдачи», п. `/dashboard`) сюда кладутся:

1. **Скриншоты дашборда** — подпапка `screenshots/`;
2. **ZIP-экспорт дашборда** из Superset (включает конфигурацию чартов,
   дашборда и метаданные датасетов).

## Как сформировать (пошагово)

1. Собери дашборд в Superset (см. `docs/Сборка дашборда в Superset.md`).
2. **Скриншоты ролей** (для демонстрации зон ответственности из ТЗ):
   - `01_gen_dir.png` — генеральный директор (фильтр `agg_level = company`);
   - `02_dir_proizvodstva.png` — директор по производству;
   - `03_dir_zakupok.png` — директор по закупкам;
   - `04_nachalnik_ceha.png` — начальник цеха;
   - `05_nachalnik_sklada.png` — начальник склада;
   - `06_manager_zakupok.png` — менеджер по закупкам.
   Сохрани в `dashboard/screenshots/`.
3. **Экспорт:** в Superset открой дашборд → меню «⋮» → **Export dashboard** →
   сохрани ZIP в эту папку (например `dashboard_export.zip`).

## Ожидаемая структура

```text
dashboard/
├── README.md               ← этот файл
├── screenshots/
│   ├── 01_gen_dir.png
│   ├── 02_dir_proizvodstva.png
│   └── ...
└── dashboard_export.zip    ← ZIP-экспорт из Superset
```

> В git хранятся только эти файлы (картинки и ZIP) — объём невелик.
> Учётные записи и RLS-правила Superset в ZIP не входят: они разворачиваются
> по `docs/Дашборд: фильтры, скопы и доступ.md` (раздел 5).
